# Portfólio — Felipe Azevedo

Site pessoal desenvolvido com HTML, CSS e JavaScript e preparado para publicação no GitHub Pages.

## Estrutura

```text
portfolio/
├── index.html
├── assets/
│   ├── style.css
│   └── script.js
└── README.md
```

## Personalização antes de publicar

1. Atualize o texto da seção **Sobre** em `index.html`.
2. Revise os projetos, tecnologias e resultados apresentados.
3. Edite o objeto `profile` em `assets/script.js` com seus links reais.
4. Adicione imagens e demonstrações somente quando puder divulgá-las publicamente.
5. Remova informações internas, dados pessoais de terceiros, imagens restritas e materiais proprietários.

## Publicar com GitHub Pages

1. Crie um repositório público chamado `FSAzevedo9.github.io`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde a publicação. O endereço será `https://FSAzevedo9.github.io`.

## Observação

Este é um ponto de partida. Confirme a exatidão das informações e substitua os links de exemplo antes de tornar o site público.
